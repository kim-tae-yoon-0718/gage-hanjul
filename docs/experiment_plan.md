# 비교 실험 계획 v1

실제 수행일은 2026-11-05다. 이 문서는 첫 정식 평가 전에 고정한다.

## 서비스와 기본 버전

대상은 광고 제작 인력이 부족한 소상공인이다. 확인한 상품 정보와 선택 사진을 입력하면 광고안 3개를 생성하고 자동 점검 및 내려받기를 제공한다. 기본 버전부터 구조화 출력, 지시와 데이터 분리, 사실 밖 주장 금지, 채널 길이 지시, 공통 검증기, 오류 안내, 사진 전처리를 갖춘다. 비교를 위해 의도적으로 기능을 빼거나 잘못된 프롬프트를 사용하지 않는다.

## 두 번의 개선 실험

1. **실험 1: 번호를 붙인 사실 원장.** 기본 프롬프트와 모델을 유지하고, 사실별 번호·원문 및 창작 요청과 사실의 구분을 추가해 근거 참조를 명시한다. 기본 버전과 동일한 평가 18건을 2회 생성해 비교한다.
2. **실험 2: 공통 검증기 기반 최대 1회 수정.** 실험 1에서 생성한 초안을 그대로 재사용한다. 공통 검증기가 문제를 찾은 경우에만 문제 목록과 초안을 제공해 최대 한 번 수정한다. 통과한 초안은 호출 없이 그대로 반환한다. 수정 후에도 실패하면 실패 상태로 제공한다. 새로 초안을 뽑아 비교하지 않는다.

## 고정 조건

- OpenAI `gpt-5-mini`, Responses API, reasoning minimal, max_output_tokens 2200, store false. 실제 반환 모델명은 호출 기록에서 확인한다.
- 가상 소상공인 6종 × 채널 3종 = 18문항, 문항당 2회 = 버전별 36개 광고 묶음, 묶음당 광고안 3개.
- 동일 입력·데이터 파일·채점 코드·검증기. 실험 실행 manifest에 SHA-256과 Git 커밋을 저장한다.
- 본 비교에서는 사진을 제외해 텍스트 파이프라인의 변화를 분리한다. 사진 경로는 별도의 기능 점검으로 확인하며 모델 개선 실험으로 세지 않는다.
- 실패·불완전 응답을 다른 모델이나 고정 광고로 대체하지 않는다. 자동 재시도는 하지 않는다.
- 정식 평가 최대 모델 호출 108회(기본 36 + 실험 1의 36 + 실험 2 수정 최대 36). 입력 길이 제한과 출력 토큰 상한을 적용한다. 사용자가 허용한 전체 상한은 $5다.

## 판정

- **공통 자동 점검 통과율**: 세 광고안 모두 개수·빈칸·채널 길이·태그·상품명·필수 문구·금지어·숫자/단위·위험 표현·근거 번호 범위·완전 중복을 통과한 비율.
- **사실성 표지 통과율**: 평가 문항에 미리 적은 금지 사실 표지가 게시 문구에 나타나지 않은 비율. 표지 정답은 생성 프롬프트에 전달하지 않는다. 이는 한정된 문자열 검사이며 의미 전체의 사실성 점수가 아니다.
- **전체 통과율**: 위 두 판정을 모두 만족한 묶음 비율. 한 광고안의 한 항목이라도 실패하면 그 묶음은 실패다. API 오류도 전체 분모에 포함한다.
- 비용은 실제 input/output 토큰에 표준 텍스트 요율(input $0.25, output $2.00 / 1M)을 적용한 보수적 추정이다. 캐시 할인을 적용하지 않아 청구서와 다를 수 있다.
- 시간은 개별 API 호출의 wall time 합이다. 실험 2는 재사용한 초안 생성 시간과 수정 시간을 합산한다. 3개 병렬 평가 작업의 전체 실행 시간과 구분한다.
- 2회 반복의 문항별 통과 일치율과 채널별 결과를 함께 보고한다. 적은 가상 평가셋이고 독립 테스트셋이 아니므로 일반 사용자 성능으로 확대하지 않는다.

## 최종 선택 기준

전체 통과율을 우선하고, 같은 품질이면 호출·비용·대기 시간이 적은 구조를 선택한다. 점수 향상이 없더라도 추가 실험을 만들지 않는다. 마지막에는 실제 생성 문구를 표본 검토하여 자동 판정의 한계를 적는다. 자연스러움·구매 전환·실사용자 만족도는 이 실험으로 검증했다고 주장하지 않는다.
