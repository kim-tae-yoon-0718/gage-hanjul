# 가게한줄 업무일지 사본

Notion 원본: https://app.notion.com/p/40f9556c393781c4b32fc59623f10894

실제 수행일과 작성일은 2026-11-05다. 사용자 요청에 따라 작업 단계를 11월 1~5일의 개별 글로 나누어 정리했다. 이 사본은 제출용 핵심 요약이며 Notion 원문에 더 상세한 기록을 연결한다.

## 11월 1일 업무일지 - 요구사항과 기획

### 수행 업무

소상공인을 위한 생성형 광고 콘텐츠라는 고정 주제를 확인했다. 핵심을 상품 정보·선택 사진에서 광고 문구 3안을 만드는 흐름으로 정했다. 사용자, 입출력, 지원 채널, 제출 산출물과 평가 기준을 정리했다. DB·클라우드 배포보다 로컬 서비스와 모델 실험에 집중했다.

### 완료도와 판단

기획 단계 100%. 확인 사실과 창작 요청을 분리해야 한다고 판단했다. 광고가 자연스러워도 미확인 할인·효능을 추가하면 그대로 쓸 수 없기 때문이다. OpenAI만 사용하고 GPU·Hugging Face·Colab은 사용하지 않는다. 완료된 기본 버전 뒤 개선 실험을 두 번만 진행하기로 했다.

### 다음 작업

입출력 규격, 기본 생성 지시, UI, 공통 검증과 고정 평가셋을 구현한다. 사용자 개인의 감정이나 직접 수행 경험은 확인하지 않았으므로 대신 꾸며 쓰지 않았다.

## 11월 2일 업무일지 - 기본 구현과 검증

### 수행 업무

Pydantic 입력·출력 규격, 공식 Responses API 호출, Streamlit 화면과 CLI를 구현했다. 상품 사실, 채널, 말투, 필수 문구와 금지어를 입력받고 광고 3안과 점검 내역을 내려받도록 했다. 사진을 1024px 이하 JPEG로 변환하고 메타데이터를 제거했다. 고정 가상 평가 18건을 2회씩 생성했다.

### 완료도와 결과

기본 서비스 단계 100%. 경계 테스트 11개와 앱 초기 화면 테스트 1개를 통과했다. 실제 광고 생성도 성공했다. 전체 통과는 14/36(38.89%), 사실성 표지 통과는 32/36이었다. 추정 비용 $0.037017, 호출 시간 중앙값 4.988초였다.

### 발견과 시행착오

짧은 배너의 길이 초과, 해시태그의 # 누락, 상품명 원문 차이와 미확인 할인 표현을 발견했다. 앱 테스트의 상대 경로 문제를 절대 경로로 수정했다. 제한된 실행 환경의 앱 테스트 지연은 로컬 실행 권한으로 재검증해 해소했다. 점수를 높이기 위해 평가 자료나 판정 기준을 바꾸지 않았다.

### 다음 작업

사실 원장을 명시하는 첫 개선을 같은 평가로 비교한다.

## 11월 3일 업무일지 - 첫 번째 개선 실험

### 수행 업무

확인 사실에 번호와 원문을 붙이고 광고에 사용할 사실을 먼저 선택하게 했다. 요청문에만 있는 할인·배송·인증·효능은 사실의 근거가 아님을 구분했다. 같은 모델·평가셋·채점기·출력 한도로 36묶음을 새 생성했다.

### 완료도와 결과

첫 번째 개선 실험 100%. 전체 통과 18/36(50.00%), 사실성 표지 통과 36/36을 확인했다. 추정 비용은 $0.040105, 호출 시간 중앙값은 5.450초였다. 길이·해시태그·상품명 오류는 남았다. 기본과 첫 개선은 새 생성이므로 무작위성·시점 영향이 남는다.

### 발견과 기록 한계

근거 원장은 사실 혼동을 줄이는 데 도움이 될 수 있지만 형식 제약을 보장하지 못했다. 첫 실험의 커밋 기록이 권한 문제로 지연돼 원본 manifest는 이전 HEAD를 가리킨다. 실행 전 프롬프트 해시는 저장했고 실행 중 구현을 변경하지 않았다. 실제 첫 개선 코드는 9394cc1에서 확인한다.

### 다음 작업

첫 실험의 초안을 그대로 재사용하고 실패 초안만 한 번 수정한다.

## 11월 4일 업무일지 - 두 번째 개선 실험

### 수행 업무

실험 1의 36개 초안 중 공통 검증을 통과한 18개는 그대로 유지했다. 실패한 18개에만 오류 목록을 제공하여 최대 한 번 수정했다. 평가 정답 표지는 수정 요청에 전달하지 않았다. 통과 초안 무호출, 한 번 수정, 실패 상태 유지 테스트를 추가했다.

### 완료도와 결과

두 번째 개선 실험 100%. 실패 초안 18개 중 13개를 복구해 전체 통과 31/36(86.11%)을 확인했다. 사실성 표지는 36/36, 길이는 32/36이 통과했다. 초안 생성분을 포함한 서비스 36회분 추정 비용은 $0.063829, 호출 시간 중앙값은 8.666초였다. 이번 추가 수정 비용만은 $0.023724다. 전체 자동 테스트 15개를 통과했다.

### 남은 문제와 판단

5개 묶음에 길이·상품명 문제가 남았다. 품질 통과율을 우선해 이 구조를 기본으로 선택했다. 시간과 비용 증가를 함께 보고한다. 승인된 두 번의 개선을 마쳤으며 세 번째 모델 개선 실험은 진행하지 않는다.

## 11월 5일 업무일지 - 최종 확인과 제출 자료

### 수행 업무

최종 구조를 앱과 CLI의 기본으로 연결했다. 실제 CLI, 합성 그림을 사용한 선택 사진 입력, Chrome에서 광고 생성과 JSON 내려받기를 확인했다. 사용법 중심 README, 실패 원본, 채널별 결과, 비용 중복 제거 분석, 직접 읽은 18개 광고안의 검토 기록과 보고서를 작성했다. Notion에는 상위 프로젝트·업무일지와 날짜별 별도 글을 구성했다.

### 완료도와 근거

로컬 구현·실험·검증·제출 문서 준비 100%. GitHub 새 저장소에는 최종 산출물을 올리고 원격 파일을 확인한다. 실제 API 비용 기록은 정식 비교 90회 $0.10084625, 별도 기능 점검 7회 $0.01063050, 합계 추정 $0.11147675다. 캐시 할인을 반영하지 않은 추정으로 청구서와 다를 수 있다. 사용자 허용 한도 $5 안에서 진행했다.

### 발견과 한계

표본에서 부정확한 커피 태그, 확인되지 않은 신선함·식감 수식어, 예약 CTA와 가게 이름 띄어쓰기 차이를 확인했다. 따라서 자동 점검 통과를 사실성 전체 검증으로 표현하지 않았다. 실제 소상공인 사용자 만족도나 구매 전환·부하·모바일 사용성은 평가하지 않았다.

### 후속 과제

독립 평가셋, 의미 단위 사실 검증, 한국어 고유명 보존과 짧은 배너 조립, 실제 편집 시간 측정은 향후 후보로만 남긴다. 추가 고도화 실험은 실행하지 않았다. 사용자는 Notion 접근 권한과 제출 기한에 맞춰 LMS 제출을 직접 확인해야 한다.
