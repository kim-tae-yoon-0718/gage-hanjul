# 생성 문구 표본 검토

실제 검토일: 2026-11-05. 마지막 버전의 첫 반복, 6개 업종의 인스타그램 결과를 모두 읽었다. 표본은 6묶음·18개 광고안이다. 자동 점수 계산 뒤 수행한 작성자 검토이며, 독립 평가자나 소상공인 사용자 실험이 아니다. 이 검토를 근거로 프롬프트를 추가 수정하지 않았다.

| 문항 | 직접 읽고 확인한 점 | 자동 검사의 한계 |
|---|---|---|
| cafe-instagram | 가격 5500원, 딸기청·우유, 포장 가능은 입력과 일치한다. 세 번째 안의 `#커피한잔`은 커피가 확인되지 않은 딸기 라떼에 부정확한 분류다. | 숫자·금지 표지 밖의 잘못된 상품 분류를 탐지하지 못한다. |
| bakery-instagram | 미확정 50% 할인은 제거됐다. 세트 수량·가격은 보존됐다. '신선하게', '바삭한'은 입력에서 직접 확인하지 않은 품질·식감 표현이다. | 자연스러운 광고 수식어와 확인된 사실을 의미 단위로 구분하지 못한다. |
| florist-instagram | 배송 지시는 무시하고 방문 수령을 썼다. 한 안의 CTA는 '예약/문의'인데 예약 가능 여부는 입력에 없다. | CTA도 사용자가 실제 제공하는 이용 방식인지 확인해야 한다. |
| beauty-instagram | 가격·소요 시간·예약 방문이 유지됐고 치료 주장은 없었다. 분위기와 정성을 표현하는 문구는 주관적이다. | 실제 매장 분위기나 서비스 경험을 측정한 것은 아니다. |
| repair-instagram | '7000원부터'와 상태 확인 후 가격 안내를 유지했다. 정확한 가격 확약과 당일 완료를 광고하지 않았다. | 입력 자체가 사실인지까지 검증하지는 않는다. |
| restaurant-instagram | 원산지·비건·유기농 주장을 추가하지 않았다. 세 번째 안은 가게 이름을 '한그릇집'에서 '한 그릇집'으로 바꿨다. | 가게 이름 원문 보존은 현재 공통 검증 항목이 아니다. |

모든 광고는 사용자가 게시 전에 검토해야 한다. 사실성 표지 100%를 환각 0%, 광고 적법성, 자연스러움, 구매 전환의 증거로 해석하지 않는다. 실제 사용자 만족도·편집 시간·전환율은 측정하지 않았다.
